# Easee

- **HQ:** Norway
- **Regions:** Europe, UK
- **Site:** https://easee.com/

Compact ‘charging robot’ on a backplate. Fully dynamic 1φ/3φ including Norwegian IT (max ~12.7 kW at 32 A 3φ IT). Built-in Type B-class RCD. Equalizer for whole-building load/PV. OCPP 1.6 via Easee API (not always native box-to-backend).
