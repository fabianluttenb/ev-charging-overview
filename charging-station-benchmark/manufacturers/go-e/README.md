# go-e

- **HQ:** Austria
- **Regions:** Europe
- **Site:** https://go-e.com/

Gemini is the wall-mounted Mode 3 unit. Gemini flex is the portable Mode 2 IC-CPD (CEE inlet + adapters). Open HTTP/MQTT/Modbus API. Charger PRO: MID, ISO 15118 / V2X hardware-ready, OCPP 1.6, IP66, §14a EnWG.
