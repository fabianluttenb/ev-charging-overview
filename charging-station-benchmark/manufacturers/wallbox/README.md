# Wallbox

- **HQ:** Spain
- **Regions:** Europe, North America, Latin America
- **Site:** https://wallbox.com/

Pulsar family is the compact residential staple. Plus = Wi-Fi/BT, IP54. Max = Ethernet, IP55/IK10, OCPP. Power Boost / Eco-Smart need an external meter. Copper SB / Pulsar Pro for business. Quasar is bidirectional (out of 22 kW AC-only scope).
