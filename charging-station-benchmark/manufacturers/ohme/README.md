# Ohme

- **HQ:** United Kingdom
- **Regions:** UK, Europe
- **Site:** https://www.ohme-ev.com/

Home Pro is the Mode 3 7 kW wallbox (tariff-aware, Octopus, PEN). ePod is the Mode 2 portable 13 A / ~3 kW smart granny charger.
