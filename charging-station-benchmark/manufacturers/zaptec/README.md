# Zaptec

- **HQ:** Norway
- **Regions:** Europe, UK, Oceania
- **Site:** https://www.zaptec.com/

Strong in apartment / workplace load and phase balancing. Go / Go 2 for homes; Pro for sites (PLC between units). TN/IT/TT. Go 2: MID Class B, ISO 15118 hardware, RFID, LCD. ADAC 2025 Zaptec Pro M&E note 1.8.
