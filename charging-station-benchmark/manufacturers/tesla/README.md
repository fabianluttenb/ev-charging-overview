# Tesla

- **HQ:** United States
- **Regions:** North America, Europe, East Asia
- **Site:** https://www.tesla.com/support/charging/wall-connector

Gen 3 Wall Connector is Mode 3. NA: 12–48 A @ 208/240 V (11.5 kW), CCID20, NACS or Universal (J1772). IEC/TW: Type 2, up to 32 A 1φ (7 kW) or 32 A 3φ (22 kW on 400 V). Mobile Connector is the Mode 2 travel IC-CPD with plug adapters.
