# myenergi

- **HQ:** United Kingdom
- **Regions:** UK, Europe, Oceania
- **Site:** https://www.myenergi.com/

Zappi: 7 kW 1φ (UK) or 22 kW 3φ export SKUs. Eco / Eco+ solar diversion with harvi/CT. OCPP on later firmware. PEN-fault protection for UK PME. Very common with UK PV.
