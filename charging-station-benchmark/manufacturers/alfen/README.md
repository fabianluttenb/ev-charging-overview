# Alfen

- **HQ:** Netherlands
- **Regions:** Europe
- **Site:** https://alfen.com/en/ev-chargers

Benelux install-base leader. Eve Single S-line (11 kW 3φ) vs Pro-line (22 kW). Certified OCPP 1.6 2nd edition and 2.0.1. P1 / Modbus / Linky TIC for smart charging. Eichrecht DE SKUs. ADAC 2025 Eve Single Pro-line note 1.9.
