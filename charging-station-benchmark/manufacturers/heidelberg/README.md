# Amperfied / Heidelberg

- **HQ:** Germany
- **Regions:** Europe
- **Site:** https://www.amperfied.com/

Former Heidelberg Wallbox (Energy Control / Connect). Analog 0–10 V / PWM load management without a cloud. Energy Control is the cheap, robust, no-app option. Connect adds WLAN/OCPP. Brand now Amperfied (Porsche/Volkswagen group industrial).
