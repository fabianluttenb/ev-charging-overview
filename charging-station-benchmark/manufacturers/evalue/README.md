# Evalue / ChargingBOLT

- **HQ:** Taiwan
- **Regions:** East Asia
- **Site:** https://www.evalue.com.tw/

Taiwan-market wallboxes with adjustable 16/24/32/40/50 A @ 220 V 60 Hz. 40 A SKU = 8.8 kW on a 50 A RCCB. Type 1 (J1772) and Type 2. CNS 15511 + VPC. Requires Type B or EV Type A RCCB in TW.
