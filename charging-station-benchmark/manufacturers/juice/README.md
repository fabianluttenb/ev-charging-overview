# Juice Technology

- **HQ:** Switzerland
- **Regions:** Europe, North America
- **Site:** https://juice.world/

Juice Booster is a drive-over IC-CPD: portable Mode 2 on household/CEE adapters, Mode 3 as a Type 2 charging cable. Booster 2/3 up to 22 kW; Booster 3 air up to 11 kW.
