# ABL

- **HQ:** Germany
- **Regions:** Europe
- **Site:** https://www.abl.de/

eMH1 is the classic simple German wallbox (ADAC 1.0 in 2018). eM4 Single/Twin is the current connected/Eichrecht line. ADAC 2025 eM4 Single note 1.9.
